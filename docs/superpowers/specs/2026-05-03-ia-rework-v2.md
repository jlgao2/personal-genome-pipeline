# IA Rework v2 — 3 Tabs by Mental Model

> **Status:** PROPOSAL · awaiting redline
> **Triggered by:** "I want today's interventions, long term plan and vision, and fixed variables/current profile as the three tabs"

## Why this is sharper than v1

v1 was Today / Trends / Profile. The split was time-based (now / over time / about me). It worked, but Trends and Today blurred — what's a 7-day recap if not "today's adherence"?

v2 splits by **mental model**: tactical · strategic · static. Each tab answers a different question.

| Tab | Question it answers | Mental mode |
|---|---|---|
| **Interventions** | "What do I do right now?" | tactical · acts on present |
| **Plan & Vision** | "Where am I going, and is it working?" | strategic · acts on direction |
| **Profile** | "What about me doesn't change?" | static · context |

This is also closer to what an actual coach would think about: "today" / "block we're in" / "athlete file."

## Tab 1: Today's interventions

Everything that demands a decision in the next 24 hours.

**Hero strip** — most-actionable thing distilled to one sentence ("Sleep 5h. Skip strength. Walk + Day 5 yoga.")

**Adapted Session** — traffic light + intensity % + swaps + the prescribed program below. Adherence chip showing if Garmin already recorded today.

**Action Loop** — compact: cards that have *changed state* since yesterday at top, stable cards collapsed.

**Stack** — only today's doses, grouped by morning / pre-workout / evening.

**Pre-flight check** — 5-item daily checklist.

**Med Watch alerts** — only firing alerts. The "heads-up classes" reference moves to Profile.

What moves OUT vs current: the hero card stays, weekly recap and vitals leave to Plan, genome findings leave to Profile.

## Tab 2: Long-term plan & vision

The strategic surface. Where am I heading. Is it working.

**Vision statement** (italic, dim, large) — one paragraph. Hand-edited in `health_profile.json`. Example:

> "Return to trail running by September. Lose 7 kg. Peroneal pain-free under load.
>  Build a system where bloodwork → action without me thinking about it."

**Goals with timelines + progress** — list with progress bars:
- Weight: 97 → 90 kg by 2026-09-01 *(35% there over 16 weeks)*
- Peroneal pain threshold: 3 km → 8 km running *(currently 3 km, no change yet)*
- VO₂Max: 51 → 55 *(101% — at maintenance)*
- HbA1c <5.6% *(awaiting MyChart bundle)*

Each goal: target value + deadline + current value + visual delta against the linear target line. New `goals` schema in `health_profile.json`.

**Block roadmap** — a horizontal timeline:
- *Now (next 4 weeks)*: peroneal eccentrics, baseline bloodwork, methylated B-complex
- *Block 2 (2-3 months)*: progressive return to longer running, recheck homocysteine
- *Block 3 (3-6 months)*: trail running, body comp re-eval

Pulled from `action_plan_immediate` + `short_term_4_to_8_weeks` + `medium_term_2_to_3_months` (the latter two are currently in the JSON but not surfaced).

**Trends as evidence** — Vitals sparklines (full available range, not 90d) + Workouts cumulative stats:
- Total volume last 30/90/365 days
- Sport spread donut chart (cycling 40%, tennis 18%, etc.)
- Sleep adherence streak
- RHR baseline over time

**Weekly Recap** moves here as the leading-indicator that the plan is working.

## Tab 3: Fixed variables / current profile

Things that don't change in the next 6 months.

**Demographics** — age, height, sex, ancestry, current weight.

**Vulnerability profile** — "Generalized tendinopathy susceptibility" + the affected sites pills.

**Active conditions** — peroneal, hip, SLAP, elbow.

**Current medications** — minoxidil, finasteride.

**Genomics** — full 149 findings, 8 expandable sources.

**Heads-up med classes to mention to prescribers** — fluoroquinolones, statins, etc. (Med Watch alerts that *are firing* live in Interventions; the *reference list* lives here.)

The mental rule: if it could change in 30 days, it goes in Plan. If it doesn't change in 6 months, it goes here.

## What's actually new

- **`goals[]`** structured field in `health_profile.json` — each entry has `name`, `target_value`, `current_value`, `deadline`, `units`, `direction`. Renderable as a progress bar.
- **`vision_statement`** field — single italic paragraph.
- **Block roadmap** rendering — pulls from existing `action_plan_*` fields in the profile JSON. The fields exist already; they're just not surfaced.
- **Cumulative stats** for workouts — total volume / sport donut. Computed in `build_vitals.py` as part of the bundle.

Everything else in the rework is *moving panels*, not new code.

## Decisions for you to call

1. **Hero strip = one sentence vs the current larger card?** I lean toward one sentence + a tap-to-expand. The current card has a lot of explanation that lives better in Action Loop.

2. **Sleep streak / adherence streak as a visual element on Plan?** Like a contribution graph (each day a green/amber/red square). Powerful but adds rendering complexity. Vote yes/no.

3. **Block roadmap as a real horizontal timeline (with weeks/months marks) or just three vertical sections?** Real timeline is more striking but harder on mobile. Three sections is honest.

4. **Goals: hand-author in health_profile.json or extract from action_plan_immediate text?** Hand-author is cleaner; the existing text is informational and not parseable into goal/target/deadline. So I'd add a new `goals` field and have you author 5-7 of them.

5. **Med Watch split — alerts that *fire* go to Interventions, reference list goes to Profile.** Sane?
